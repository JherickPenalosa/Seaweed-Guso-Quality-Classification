# Seaweed (Guso) Quality Classification Using Mobile Image Processing

## Summary
Guso is a Mobile and Web Application system that uses image processing techniques to
automatically classify the quality of seaweed (guso) based on visual characteristics such as
color, texture, and size. The system is designed for seaweed farmers, traders, and quality
inspectors who need a fast, consistent, and objective way to grade harvested seaweed without
relying solely on manual visual inspection. By simply uploading or capturing an image, users
can quickly determine the quality grade of their guso, helping speed up sorting, pricing, and
quality control processes in the seaweed industry.

## Current stack
Flutter Web / Dart; planned REST API and PostgreSQL.
